# Comfort Arch 2026 — 장난용 화면보호기 🌸

**대놓고 "장난이에요" 라고 알려주는** 전체화면 화면보호기입니다.
처음부터 장난이라는 안내 배너가 뜨고, 가운데에 원하는 그림이 벚꽃과 함께 나옵니다.

> 속이는 용도가 아니에요. 그래서 이렇게 만들어져 있습니다:
> - 🔇 **소리 없음** — 볼륨을 전혀 건드리지 않습니다. (경고음 루프 없음)
> - 🧷 **작업표시줄을 잠그거나 숨기지 않습니다.**
> - 🙂 **커서가 그대로 보입니다.**
> - ⏹ **아무 키 / 클릭 / 마우스 이동으로 즉시 닫힙니다.**

---

## 그림 바꾸기 (제일 중요!)

보여줄 그림은 **`center-photo.png`** 파일입니다.
원하는 그림(예: 좋아하는 포스터·사진)을 `center-photo.png` 라는 이름으로 이 폴더에 넣으면 그대로 나옵니다.

> 참고: 저작권이 있는 이미지는 개인적으로 쓰는 건 괜찮지만, 공개 저장소에 올리거나
> 배포할 때는 권리 문제가 생길 수 있어요. 그래서 이 저장소에는 특정 그림을 넣어두지 않았습니다.

---

## 실행 방법

### 방법 A. 브라우저로 (가장 간단, 어떤 OS든)
`index.html` 을 더블클릭해서 브라우저로 엽니다.
- **화면을 클릭** → 전체화면
- **아무 키 / 더블클릭** → 닫기 (브라우저 특성상 전체화면 해제까지만 될 수 있어요)
- **Esc** → 전체화면 해제

### 방법 B. 윈도우에서 진짜 화면보호기처럼 (PowerShell)
`run.bat` 을 더블클릭하면 `ComfortArch2026.ps1` 이 전체화면으로 실행됩니다.
- **아무 키 / 클릭 / 마우스 이동** → 즉시 닫힘

---

## `.exe` 로 만들기 (선택)

Windows PowerShell에서 아래를 실행하면 `ComfortArch2026.exe` 가 만들어집니다.

```powershell
.\build-exe.ps1
```

- 아이콘을 넣고 싶으면 `icon.ico` 파일을 같은 폴더에 두고 다시 실행하세요.
  (PNG는 [아이콘 변환 사이트]나 이미지 편집기로 `.ico` 로 바꾸면 됩니다.)
- 만들어진 `ComfortArch2026.exe` 와 `center-photo.png` 를 **같은 폴더**에 두고 실행하세요.

## 진짜 Windows 화면보호기(`.scr`)로 쓰기 (선택)

위에서 만든 `ComfortArch2026.exe` 의 확장자를 `.scr` 로 바꾸면
`C:\Windows\System32` (또는 개인 폴더)에 넣고 **설정 → 화면 보호기**에서 고를 수 있어요.
`center-photo.png` 도 같은 폴더(혹은 `scr` 옆)에 있어야 그림이 나옵니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 브라우저용 장난 화면보호기 (벚꽃 연출) |
| `ComfortArch2026.ps1` | 윈도우용 전체화면 화면보호기 스크립트 |
| `run.bat` | 위 스크립트를 더블클릭으로 실행 |
| `build-exe.ps1` | `.ps1` → `.exe` 빌드 도우미 (ps2exe) |
| `center-photo.png` | **보여줄 그림 — 원하는 이미지로 교체** |
